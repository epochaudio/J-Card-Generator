范围确认：所有当前功能、选项和业务行为保持不变，只调整展示位置、分组、折叠和文案。用户已明确确认开始实施，并随后授权升级至 2.1.1、更新文档与提交；未打包或发布。

关联文档：[维护与功能规划](../MAINTENANCE.md)、[使用说明](../HELP.md)、[README](../README.md)

本次同步：以用户最新确认的“所有当前功能和行为保持不变，只降低界面复杂度”为最高边界。下文取代此前新增整体风格组合、局部风格撤销、自动配置引导和改变默认值等规划。已完成的 DeepSeek 统一入口属于当前基线，不恢复历史模型选择。

## 1. 目标与使用方式

用户要求：减少同时呈现的选择，降低认知门槛；不删除现有选择，不改变选择后的效果。

产品目标：第一次使用的人，无需打开高级设置，即可添加封面与曲目、查看成品、保存作品并导出 PNG。熟练用户仍能找到原有细节控制。

本文同时记录后续方案与已完成范围。实施前核对当前代码；完成一个阶段后，在第 12 节填写实际变更、验证结果与剩余事项，再更新阶段状态。

设计原则：

1. 主界面围绕完成作品组织，设置只承载长期配置。
2. 保持现有默认值，通过分组和折叠减少同时暴露的信息。
3. 先展示结果，再提供细节调整；收起内容要有摘要。
4. 尺寸、内容覆盖、服务商与费用等重要决定保持明确。
5. 不增加简单／专家模式，不要求用户先选择自己的使用级别。
6. 界面折叠不删除数据，切换页签不触发 AI、不修改作品。
7. 同一作品、相同设置与相同操作，调整前后的业务状态和成品结果应一致。
8. 展开更多选项只是展示行为；不得新增启用条件、必填项、确认步骤、自动请求或自动应用。

## 2. 审阅背景与现状边界

前轮审阅发现：顶部作品操作分散在两排；智能搭配和手动设计先于素材输入出现；外观参数、内容组织、物理尺寸混排；AI 设置同时展示三类服务商以及模型输入、搜索与选择控件。

以上是讨论时的历史观察。2026-09-10 同步核对设置界面、配置规范化逻辑与主维护文档 F10.13，AI 设置已采用 DeepSeek 统一入口，原模型选择器已移除。后续不得按旧方案恢复服务商分支或模型选择。工作区另有未提交改动，实施其余阶段前仍需重新核对。

## 3. 总体信息结构

保留左侧成品预览、右侧编辑。右侧使用两个固定页签：

| 页签 | 内容 | 默认行为 |
| --- | --- | --- |
| 内容 | 图片、专辑资料、A/B 面曲目、录音资料 | 初次打开作品首先进入 |
| 外观 | 现有字体、配色、排版、智能搭配与盒型尺寸 | 用户主动切换 |

两个页签可随时切换，不构成强制步骤向导。分别保留本次操作的滚动位置。保存和导出始终位于顶部，不受页签影响。

折叠区中的错误仍须可见，可提供展开入口；保持现有校验触发时机与阻断条件，不新增自动跳转流程。

## 4. 顶部菜单与作品状态

建议结构：**带藏 ｜ 作品 ▾　作品名称 · 保存状态 ｜ 保存　导出图片 ▾　设置**。

| 入口 | 内容与行为 |
| --- | --- |
| 作品 | 新建作品、打开作品、另存为；原版本与许可等信息归入关于带藏；使用帮助仍见 HELP.md，不新增帮助业务流程 |
| 保存 | 保存可继续编辑的作品；首次保存选择位置 |
| 导出图片 | 主按钮直接导出 PNG，不每次弹出格式选择 |
| 导出下拉 | 导出矢量图 SVG，说明用于进一步排版与编辑 |
| 设置 | AI 服务配置 |

维护规则：

- 合并两排工具栏；由外观页签替代顶部设计跳转。
- 新建使用清楚的文字，避免重置图标与刷新、撤销混淆。
- 所有入口调用原有处理函数，保留新建、打开、保存、另存为、导出的现有流程及未保存修改保护。表中描述不授权调整桌面与浏览器各自的保存行为。
- 作品文件已保存、草稿已自动保留、浏览器已下载副本必须分别表达。
- 导出图片不能把尚未保存的作品标记为已保存。
- 版本、许可、群信息与官网归入关于；预览附近保留尺寸和成品问题。
- 桌面原生菜单与快捷键保持不变；本轮整理应用内工具栏。

## 5. 内容页

### 5.1 区域顺序

| 区域 | 默认可见 | 按需出现 |
| --- | --- | --- |
| 封面图片 | 缩略图、添加／更换图片 | AI 生成图片、移除图片 |
| 专辑信息 | 专辑标题、艺术家 | 发行日期、目录编号、标语 |
| 曲目 | 导入曲目、A/B 面列表、各面时长、添加曲目 | 单曲备注等补充字段 |
| 录音与补充资料 | 标题及已填写摘要 | 设备、音源、录音日期、厂牌、上下备注 |

### 5.2 图片与资料导入

- 上传图片是主要入口；展开 AI 生成后才展示画面描述与生成操作。
- “AI 图片提示词”改为“描述想要的画面”；生成提示词入口改为次要操作“帮我写描述”。
- 现有“智能补足信息”可改名为“从封面补全资料”；保留原可用条件、识别、搜索与核对流程。
- 导入继续默认补空字段；替换已有内容需明确选择。取消、失败或过期结果不覆盖作品。
- 第二张图只在双封面布局中展示。切换单封面时保留第二张图，切回后恢复。
- “导入曲目”展开提供搜索专辑与粘贴文本；MusicBrainz 在搜索界面作为来源说明。

### 5.3 资料与设备预设

- 收起的补充资料展示摘要，例如“已填写设备、音源”。摘要不代替作品内容。
- 现有设备预设可整体折叠；全部槽位、名称编辑和保存操作保留，不新建预设管理流程或改变空槽位行为。
- 保留现有预设数量与本机存储方式，不在本轮扩展预设系统。
- 字段隐藏后仍参与作品保存与恢复；不因隐藏将值重置为空。

## 6. 外观页

实际分组：封面设计（字体、颜色与背景、封面排版、盒子脊宽）→ 智能搭配 → 脊背与内折页。分组可以折叠，原有独立控制关系保持不变。

### 6.1 现有字体与配色

- 保留所有当前字体主题、色板、背景模式、强调色与图片取色选项。
- 不新增组合风格，不将字体、配色、标题尺寸绑定成一次操作，不挑选少数主题替代完整列表。
- 保留原有小样与实时成品预览，不新增候选生成或效果预计算流程。
- 手动切换字体、配色后的关联重置规则严格沿用当前代码，不因本轮布局调整增加或减少副作用。
- 不新增风格应用撤销；保留已经存在的智能搭配撤销功能及其原有边界。
- 不新增已自定义状态判定。已有状态与说明可以移动，但不改变其判断逻辑。

### 6.2 智能搭配

- 保留“生成三套搭配”及现有操作；风格描述可在补充要求内，字体与配色锁定可在保留当前样式内展开。
- 描述、锁定默认值和校验规则保持现状；收起时显示已有要求或锁定状态摘要。
- 最多展示三套通过检查的候选，不足时如实说明。
- 候选默认展示成品、名称、一句特点、查看大图与应用。
- 模型参数、字重、倾斜角度、修订过程等进入详情。
- 成品省略与可读性问题仍需直接提示。
- 生成不等于应用；用户应用后才写入作品。预览、应用与撤销不调用 AI。
- 保留取消、过期结果防护、本地检查与现有成品复核机制，本轮不改变生成质量规则。

### 6.3 控件位置清单（全部保留）

| 当前概念 | 目标位置与处理 |
| --- | --- |
| 字体、完整配色 | 分组展示，保留独立选择与所有现有选项 |
| 深色、浅色、封面背景、图片取色 | 收进颜色与背景，避免与完整色板平级竞争 |
| 强调色、从封面推荐 | 颜色调整内，沿用当前显示与禁用条件 |
| 正面布局 | 改名封面排版，保留原选项与原有小样 |
| 标题尺寸、纸纹 | 封面排版内，保留原条件与值 |
| 强制大写 | 与原有脊背开关一起保留在脊背与内折页内 |
| 标准／古典／合辑 | 改名曲目组织，归入内容页曲目区 |
| Short Back 模式 | 改名内折页内容，归入外观细节 |
| 脊部短标题、翻转脊部 | 集中在脊背调整 |
| 标语对齐 | 归入标语相关区域，保留现有可用条件；不新增“有标语才可设置”的限制 |
| 极简脊部 | 保留原开关、禁用状态与原因，仅调整位置 |
| 盒子脊宽 | 盒型与尺寸，始终容易查找 |

曲目组织与视觉风格独立，不根据风格推断或修改古典、合辑结构。盒型可显示“标准盒 · 脊宽 12.7 mm　修改”；实际数值读取现有尺寸定义，不在界面重复硬编码。

## 7. AI 设置：已实现基线与后续约束

本节 7.1、7.2 记录用户确认的现行产品决策；7.3 仅允许入口位置与文案整理，不增加配置流程。

### 7.1 首次配置

DeepSeek 前置并明确标记“推荐”。默认展示固定模型、一个 API Key 输入框、能力范围、简短费用说明以及保存／关闭；关闭未保存的修改不生效。

- DeepSeek `deepseek-flash` 固定承担文字生成、曲目解析、封面识别、智能搭配与成品视觉复核，共用一个 DeepSeek API Key；不提供文本／视觉服务商或模型选择。
- 只有封面生图保留一个可选开关；新配置默认关闭，开启后从阿里云或火山引擎中选一家，填写对应密钥。关闭时不要求生图密钥。不要重新增加文案、识图等能力开关。
- 生图服务使用项目已适配的固定模型，不再读取模型列表或要求手工填写 ID。
- 保存前明确展示将用于哪些功能；不能暗中改用另一服务商。
- 未配置 AI 不阻断手工编辑、作品保存与图片导出。

### 7.2 旧设置自动收口，不保留高级模型配置

- AI 设置格式为 v5，旧设置自动收口，不要求用户理解版本、重新选择模型或执行手工迁移。
- 已有 DeepSeek 密钥继续使用；阿里云与火山引擎密钥仅作为可选生图凭据保留，不因持有密钥自动开启生图。不将其他平台密钥当作 DeepSeek 密钥。
- 历史文本／视觉服务商和自定义模型值由新结构取代；撤销此前“保留多服务商组合与自定义模型”的规划。作品内容与外观兼容要求不受此设置迁移决策影响。
- 不提供高级模型区、模型列表、手工 ID 或接入点入口。
- 打开或保存设置不自动发起付费内容生成。
- 只保存成功时提示已保存；密钥有效、模型可调用等结论必须由相应证据支持。
- 密钥沿用现有存储边界，不进入作品与草稿；修改未保存时取消应保留原配置。

迁移核对事项：当前 `normalizeAISettings` 会保留已有合法的 `imageProvider`；新配置或无生图服务的配置为空。因此“默认关闭”不能写成“所有旧配置迁移后强制关闭”。旧配置已选择生图服务的具体保留行为，后续回归须覆盖；本次仅记录代码事实，不修改迁移逻辑。

### 7.3 设置入口整理（仅展示调整）

现有设置入口可以移动或统一名称为“AI 服务设置”，继续打开同一设置窗口。保留原本的未配置提示、按钮禁用条件、保存与关闭行为。

不新增点击生成后自动打开设置、自动定位配置、保存后自动续发请求等流程。原本支持的返回或焦点恢复行为继续保留。文字、识图与生图的实际服务路由不变。
