# Tape Cover Generator 1.6.0

- 新增作品打开、保存、另存为与自动草稿恢复。
- 支持阿里云百炼、火山引擎和 MiniMax，桌面密钥使用系统加密存储。
- 新增出版排版、编辑左齐布局、三档标题、编辑衬线字体及三套完整色板。
- 字体、配色与布局集中在右侧设计面板；导出嵌入随包字体。
- 作品格式升级至版本 2，兼容读取版本 1；旧版应用不能打开新格式，建议升级旧作品时另存为。

提供 macOS Apple Silicon arm64 DMG 与 Windows x64 NSIS EXE，附 SHA-256 校验文件及各平台构建记录。

macOS 使用本地临时签名，未经 Apple 公证；Windows 安装包未签名。自动校验覆盖安装包完整性、架构、版本及资源，不代表已完成 Windows 实机安装或实体打印验证。
