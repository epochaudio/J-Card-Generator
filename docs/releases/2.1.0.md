# 带藏 · TapeFolio 2.1.0

- 新增 AI 文字样式：可按标题、艺术家、副标题、标语、曲目、备注和资料分别设置真实字重、几何倾斜及水平宽度，预览与 SVG / PNG 导出共用排版结果。
- 新增成品视觉复核：智能搭配候选通过本地检查后，将实际展开图交给同一视觉模型复核；本地检查与视觉复核共用一次修订机会，只展示最终通过的方案。
- 新增 10.7 mm 窄脊选项，省下的 2 mm 自动加入左侧内折页；总画布、正面和右侧曲目页尺寸不变，选择随作品与草稿保存。
- 改进文字边界、重叠、字体加载和导出检查；手动编辑后若仍越界或重叠，会阻止导出并提示调整。
- 升级桌面运行时与构建链：Electron 44.3.0、electron-builder 26.16.1、Node.js 22.12+；CI 使用 Node.js 24。macOS ARM64 最低要求 macOS 13，Windows 仍为 x64。
- 改进安装包构建记录与校验：大文件分块计算摘要，记录阶段耗时与实际运行时版本，并核对 macOS / Windows 包内产物。

作品格式保持 `.jcard` v3；新文字样式需使用 2.1.0 或更新版本。新增功能已完成 114 项自动测试、字体检查、生产构建及模拟模型浏览器回归。未使用真实模型账户验收设计效果，也未完成 Windows 实机安装、Apple 公证或实体打印测试。

安装包附 SHA-256 校验文件和双平台构建记录。macOS 安装包使用临时签名，未经 Apple 公证；Windows 安装包未签名。
