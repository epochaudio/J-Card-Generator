# Tape Cover Generator 2.0.1

- 新增智能搭配：根据封面原图、专辑内容和可用字体色板生成不同方向的方案，支持字体／配色锁定、预览、应用和撤销。仅展示通过本地检查的方案。
- 新增封面智能补足：识别封面线索并搜索 MusicBrainz，核对专辑与发行版本后逐项补足。默认只补空字段，已有内容需明确选择替换。
- 新增独立视觉模型配置，支持 DeepSeek 内测型号 `deepseek-v4.1-flash-expires-on-0910`，沿用原 API 地址；内测期限与权限以服务方为准，不自动切换型号。
- 修复模型手工输入易误填搜索框的问题：实际保存值直接显示，未填写视觉型号时明确提示。
- 修复预览和 PNG 导出中内嵌字体尚未完成绘制造成的正文缺失，隔离不同预览的滤镜与裁切标识。
- 作品格式保持 v2，旧作品仍可读取；AI 设置升级为 v3，旧配置默认不启用视觉功能。

92 项自动测试与生产构建通过，新增功能已完成模拟接口交互验证；模型保存修复已通过真实界面保存与重新打开验证。真实模型效果与账户可用性未作为发布验收结果。
