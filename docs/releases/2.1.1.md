# 带藏 · TapeFolio 2.1.1

- 简化 AI 设置：DeepSeek 作为推荐且固定的文字、识图与视觉复核服务，统一使用 `deepseek-flash` 与一个 API Key；移除服务商、模型搜索、模型列表和手工模型输入。
- 封面生图保持可选且默认关闭；启用后可选择阿里云或火山引擎，并使用项目内置的适配模型。已有合法生图配置按迁移规则保留。
- 重新组织编辑界面：新建、打开与另存为归入“作品”；保存与 PNG 导出保持常驻，SVG 置于导出菜单；右侧编辑区分为“内容”和“外观”，低频选项与搭配详情可折叠。
- 保留既有字体、配色、排版、尺寸、曲目、保存与导出行为；切换编辑页签不会清空智能搭配候选或中断任务。
- 作品格式仍为 `.jcard` v3；AI 设置自动迁移至 v5，无需手工迁移。

本版本已完成 107 项自动测试、17 项字体资源检查、生产构建，以及浏览器和 Electron 44.3.0 隔离回归。对照样本的作品内容与 PNG 输出字节一致。

安装包附 SHA-256 校验文件和双平台构建记录。macOS 安装包使用临时签名，未经 Apple 公证；Windows 安装包未签名。未执行真实 AI 账户调用、Windows 实机安装、实体打印或 Apple 公证测试。
