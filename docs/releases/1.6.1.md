# Tape Cover Generator 1.6.1

- MusicBrainz 导入改为搜索专辑、选择发行版本、核对预览后确认导入，候选与版本列表支持分页。
- 保留完整艺术家署名，分别记录作曲者、演奏者、指挥；区分专辑首发日期与所选发行日期。
- 修复作品关系读取与古典误判，保留多个作品关联；缺失或不明确的层级保留原曲名，不强行合并。
- 封面优先匹配所选版本，回退时提示来源差异；主封面和第二封面在导入前分别确认处理。
- 增加请求限速、超时、有限重试与过期结果隔离；失败不覆盖当前作品。
- 保留原碟号和曲序，按容量、时长与作品连续性建议 A/B 分面，并允许手动调整。
- 新增来源信息随 `.jcard` v2 保存，旧作品仍可读；用旧应用重新保存会丢弃新增来源字段。

59 项自动测试、12 项字体资产检查与生产构建通过，完成隔离浏览器导入及保存回读验证。实时资料查询可能受远端服务超时影响，作品关系缺失和曲目时长未知会明确提示。

此文件为源码版本说明。1.6.1 尚未生成安装包或发布；既有 1.6.0 安装包不含本次修复。
