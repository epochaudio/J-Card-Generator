# Tape Cover Generator 1.6.1

- MusicBrainz 导入改为搜索专辑、选择发行版本、核对预览后确认导入，候选与版本列表支持分页。
- 保留完整艺术家署名，分别记录作曲者、演奏者、指挥；区分专辑首发日期与所选发行日期。
- 修复作品关系读取与古典误判，保留多个作品关联；缺失或不明确的层级保留原曲名，不强行合并。
- 封面优先匹配所选版本，回退时提示来源差异；主封面和第二封面在导入前分别确认处理。
- 增加请求限速、超时、有限重试与过期结果隔离；失败不覆盖当前作品。
- 保留原碟号和曲序，按容量、时长与作品连续性建议 A/B 分面，并允许手动调整。
- 新增来源信息随 `.jcard` v2 保存，旧作品仍可读；用旧应用重新保存会丢弃新增来源字段。

- DeepSeek 替换 MiniMax，增加模型获取、搜索与下拉选择；DeepSeek 仅用于文本。旧 MiniMax 配置不会自动切换至其他付费服务，需重新选择并配置。
- 移除顶部 AI 创意总监批量入口，保留文本导入、标题、标语、图片提示词与封面生成等单项功能。
- 编辑左齐布局的封面图片铺满面板宽度。
- 修复 Windows 原生构建时的 ASAR 资源校验路径，增加嵌套资源完整性回归测试。

71 项自动测试、12 项字体资产检查与生产构建通过，完成隔离浏览器导入及保存回读验证。实时资料查询可能受远端服务超时影响，作品关系缺失和曲目时长未知会明确提示。

附件提供 macOS Apple Silicon ARM64 DMG 与 Windows x64 NSIS EXE，附 SHA-256 校验文件和平台构建记录。既有 1.6.0 安装包不含本次更新。

macOS 使用临时签名，未经 Apple 公证；Windows 安装包未签名。安装包自动验证覆盖完整性、架构、版本及资源，不代表 Windows 实机安装、真实 AI 账户调用或实体打印均已验证。
